Separate Windows player for **Play in Tanuki** in the Blender, Unity, Godot, and Unreal map editors.

- Actual Tanuki climbing, gliding and movement, plus Tengu movement and free camera.
- Escape menu for switching character/camera and returning to editing.
- Authored materials, collision, lights, day/night environment presets, skyboxes and sun overrides.
- Portable map schemas 1–5. Sun overrides require schema 5.

The editor plugins install this player automatically on first use. The download is split into parts because of its size; **do not extract the individual parts**. The setup helper checks each part and the complete archive before installing.

This is a movement-only authoring preview. It contains cooked runtime assets and binaries, with no private game source. The editor plugins are distributed separately.
